# Security policy

This is a research prototype and is not hardened for untrusted model files,
profiles, manifests, or measurement CSVs. Run imported artifacts in an isolated
environment and review generated native build commands before target use.

Please report suspected vulnerabilities privately to the repository owner
through GitHub's private vulnerability reporting feature. Do not include
credentials, proprietary bitstreams, device identifiers, or confidential
hardware documents in a public issue.

Only the latest revision on the default branch is supported with security
fixes.
