# Code of Conduct

HeteroViT Infra is committed to a respectful, inclusive, and technically
constructive collaboration environment.

## Expected behavior

- Discuss designs, measurements, and code on their technical merits.
- Label assumptions, simulations, predictions, and hardware measurements
  accurately.
- Give actionable review feedback and preserve third-party attribution.
- Respect privacy; never publish credentials, private hardware documents, or
  identifying measurement data.

## Unacceptable behavior

Harassment, discrimination, personal attacks, deliberate result
misrepresentation, and disclosure of another person's private information are
not acceptable.

Project maintainers may edit or remove contributions and discussion that
violate these expectations. Sensitive concerns should be reported privately to
the repository owner through GitHub.
